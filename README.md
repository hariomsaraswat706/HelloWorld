HelloWorld Smart contract 

Description

This is a simple Solidity smart contract that stores a message on the blockchain.

The contract contains:

- A public string variable initialized with "Hello World".
- A "set()" function to update the message.
- A "get()" function to read the current message.

Features

- Store a message
- Update the message
- Retrieve the message

Technologies Used

- Solidity
- Remix IDE

Example

Initial Message:
Hello World

After calling "set("Hi Blockchain")":
Hi Blockchain
